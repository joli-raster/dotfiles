# dotfiles

These are my current **dotfiles** for:
* btop;
* foot;
* fuzzel;
* ncmpcpp;
* niri;
* nvim;
* mako;
* mpv;
* waybar, and;
* yazi.

Also comes with `.config/mimeapps.list` and an install script for the sake of convenience.
